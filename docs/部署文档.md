# 系统安装部署文档

## 1. 环境要求

| 软件 | 版本 |
|------|------|
| Java | 25 |
| Maven | 3.9.16 |
| Node.js | 23.11.0 |
| npm | 10.9.2 |
| MySQL | 8.x |
| Docker | 20.10+ |

## 2. 本地部署

### 2.1 启动后端

```bash
cd backend
mvn spring-boot:run
```

### 2.2 启动前端

```bash
cd frontend
npm install
npm run dev
```

### 2.3 初始化数据库

首次启动前执行数据库脚本：

```bash
mysql -u root -p < docs/sql/init.sql
```

或修改 `backend/src/main/resources/application.properties` 中的数据库连接配置。

## 3. Docker 部署（推荐）

项目已提供完整的 Docker 化配置，一键启动全套服务：

```
docker-compose up -d --build
```

启动后访问：
- 前端界面：http://localhost:8088
- 后端接口：http://localhost:8080

### 组成说明

| 服务 | 镜像构建 | 端口 |
|------|----------|------|
| MySQL | mysql:8.0 | 3306 |
| 后端 | 根目录 docker-compose build | 8080 |
| 前端 | Nginx 托管静态文件 | 8088 |

### Dockerfile

- `backend/Dockerfile`：多阶段构建，Maven 编译 + JRE 运行
- `frontend/Dockerfile`：Node 打包 + Nginx 托管
- `frontend/nginx.conf`：前端 Nginx 配置，`/api` 反向代理到后端容器

### 数据持久化

- MySQL 数据保存在 Docker 卷 `mysql-data`，容器重建数据不丢失
- 首次启动自动导入 `docs/sql/init.sql` 初始化脚本

## 4. 配置说明

- 数据库连接：`backend/src/main/resources/application.properties`
- Docker 环境变量：`docker-compose.yml`
- 前端代理：开发环境 `vite.config.js`，生产环境 `frontend/nginx.conf`
