## 2. 登录页

登录页包含四个 Tab：

1. 账号密码：用户名、密码、图形验证码，点击验证码图片刷新。
2. 手机验证码：手机号、短信验证码、60 秒发送倒计时。
3. 邮箱验证码：邮箱、邮箱验证码、独立 60 秒发送倒计时。
4. 微信扫码：二维码渲染、2 秒轮询、3 分钟超时自动刷新、mock 扫码/确认。

后端返回 HTTP 423 时读取：

```json
{
  "data": {
    "lockRemainingMinutes": 10
  }
}
```

登录页会把剩余时间写入本地锁定状态，展示 `mm:ss` 倒计时，并禁用四个 Tab 的登录和发送操作。刷新页面后倒计时仍然有效。

## 3. 动态路由与菜单

登录成功后，后端返回：

```json
{
  "accessToken": "...",
  "refreshToken": "...",
  "permissions": ["order:create", "order:read"],
  "menus": [
    {
      "code": "menu:repair",
      "name": "智能报修",
      "path": "/repair",
      "component": "Repair",
      "icon": "Tools",
      "children": []
    }
  ]
}
```

前端处理：

1. `setSession()` 保存 Token、用户、权限和菜单。
2. `installDynamicRoutes()` 根据 `menus` 调用 `router.addRoute('Layout', ...)`。
3. `component` 字符串通过本地组件映射懒加载，未知组件使用占位页。
4. 路由守卫检查 Token、动态路由和页面权限。
5. 侧边栏递归渲染动态菜单。

新增页面时，在后端 `permission` 表增加 `MENU` 权限，并在 `dynamicRoutes.js` 的 `viewModules` 中登记组件名即可。

## 4. v-permission

全局注册：

```js
app.directive('permission', permissionDirective);
```

使用方式：

```vue
<el-button v-permission="'order:create'">提交报修</el-button>
<el-button v-permission="['system:user:lock', 'system:user:unlock']">操作</el-button>
<el-button v-permission.all="['order:read', 'order:update']">编辑</el-button>
```

`*:*` 视为超级权限。指令只负责前端展示控制，后端 `@RequirePermission` 仍会执行接口级校验。

## 5. Axios 自动刷新

- 每个请求自动携带 `Authorization: Bearer <accessToken>`。
- 每个请求自动携带持久化 `X-Client-Fingerprint`，与后端会话指纹绑定。
- 业务接口返回 401 时，多个并发请求共享同一个 refresh 请求。
- 刷新成功后更新 Token、权限和菜单，并重建动态路由。
- 刷新失败或 refresh Token 失效时清除会话并跳转 `/login`。
- 密码、短信、邮箱登录接口的 401 不会触发刷新，避免登录错误被误判为会话过期。

## 6. 本地运行

```bash
cd frontend
npm install
npm run dev
```

默认代理到 `http://localhost:8081`。联调其他端口时：

```bash
VITE_API_TARGET=http://localhost:18081 npm run dev
```

Windows PowerShell：

```powershell
$env:VITE_API_TARGET='http://localhost:18081'
npm run dev
```
