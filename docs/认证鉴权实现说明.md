# 统一认证与动态 RBAC 实现说明

## 1. 实现范围

- Spring Boot 3.3.4 + JDK 17。
- 四种登录方式：账号密码、Spug 短信验证码、邮箱验证码、微信扫码。
- 密码连续错误 5 次锁定账号 10 分钟，锁定期间四种登录方式全部拒绝。
- 账号锁定、退出登录、刷新令牌重放、角色/权限变更时立即吊销服务端会话。
- JWT access/refresh 双令牌，refresh 每次轮换，旧 refresh 重放会吊销整个会话。
- 标准 RBAC：`user -> user_role -> role -> role_permission -> permission`。
- 权限不写入 JWT，每次请求实时查询；菜单、API、按钮共用权限标识。
- 图形验证码、手机号/邮箱 60 秒发送冷却、IP 登录限流。
- 登录记录、锁定/解锁、退出、角色变更、权限变更审计。

## 5. Token 规范

access Token 默认 30 分钟，refresh Token 默认 7 天。

JWT claims：

```json
{
  "iss": "campus-repair",
  "sub": "用户ID",
  "sid": "服务端会话ID",
  "jti": "令牌唯一ID",
  "type": "access 或 refresh",
  "iat": "签发时间",
  "exp": "过期时间"
}
```

安全机制：

1. 每个受保护请求校验 JWT 签名、有效期、类型、`sid`、`jti`。
2. `auth_session` 未吊销且 jti 一致才放行。
3. 服务端保存客户端指纹，指纹变化返回 401。
4. refresh 每次轮换 jti；旧 refresh 再次使用会立即吊销整个会话。
5. 锁定账号、修改角色、修改权限、退出登录都会使已下发 Token 立即失效。

## 6. 风控与限流

| 场景 | 规则 |
|---|---|
| 登录接口 | 每 IP 每分钟 10 次 |
| 图形验证码 | 每 IP 每分钟 30 次 |
| 短信/邮箱发送 | 同一目标 60 秒一次，每 IP 每分钟 5 次 |
| 验证码 | 5 分钟有效、最多尝试 5 次、成功后立即失效 |
| 密码错误 | 连续 5 次锁定 10 分钟 |
| 锁定期登录 | 返回 HTTP 423，`data.lockRemainingMinutes` 为剩余分钟 |
| 锁定后 Token | 会话已吊销，返回 401 |

锁定响应示例：

```json
{
  "code": 423,
  "message": "账号已锁定，请 10 分钟后再试",
  "data": {
    "lockRemainingMinutes": 10
  }
}
```

## 7. 动态权限链路

1. 登录时和每次请求都查询 `user_role -> role_permission -> permission`。
2. `PermissionService` 返回权限 code 集合和 MENU 树。
3. 拦截器读取 `@RequirePermission("order:create")`，校验当前用户权限。
4. 无权限返回 HTTP 403，即使绕过前端直接调用接口也无法越权。
5. `*:*` 为超级权限，管理端同时返回全部菜单。

前端约定：

- `permissions` 用于 `v-permission` 按钮控制。
- `menus` 用于动态注册路由和侧边栏。
- `accessToken` 放入 `Authorization: Bearer <token>`。
- `refreshToken` 仅用于 `/api/auth/refresh`，不要放进普通请求头。
- 收到 401 时重新登录；收到 423 时按 `lockRemainingMinutes` 展示倒计时。

## 8. 本地模拟与生产配置

本地默认：

```properties
app.sms.mock=true
app.email.mock=true
app.wechat.mock=true
app.auth.max-login-fail=5
app.auth.lock-minutes=10
```

生产环境关键变量：

| 环境变量 | 说明 |
|---|---|
| `JWT_SECRET` | 至少 32 字节的随机密钥 |
| `SMS_MOCK=false` | 开启 Spug 短信 |
| `ALIYUN_ACCESS_KEY_ID` / `ALIYUN_ACCESS_KEY_SECRET` | 阿里云密钥 |
| `SPUG_SMS_URL` | Spug 短信模板完整地址 |
| `SPUG_SMS_EXPIRE_NUMBER` | 短信有效时长，默认 5 |
| `EMAIL_MOCK=false` | 开启 SMTP 邮件 |
| `MAIL_HOST` / `MAIL_PORT` / `MAIL_USERNAME` / `MAIL_PASSWORD` | SMTP 配置 |
| `WECHAT_MOCK=false` | 开启真实微信授权地址 |
| `WECHAT_APP_ID` / `WECHAT_APP_SECRET` / `WECHAT_REDIRECT_URI` | 微信开放平台配置 |

说明：验证码、图形验证码和限流状态当前为单节点内存实现，适合课程演示和单实例部署。多 Tomcat 集群部署时，应把 `AuthCodeService` 与 `RateLimitService` 替换为 Redis 实现；JWT 会话和账号锁定已经落库，可跨节点生效。
