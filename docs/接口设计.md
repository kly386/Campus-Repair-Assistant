# 系统接口设计文档

> 统一返回格式：`{ "code": 200, "message": "success", "data": {...} }`（见 `ApiResponse`）

## 接口约定

- 基础路径：`/api`
- 认证方式：JWT 令牌认证（见 `docs/需求分析.md` §6）
- 角色权限：STUDENT / WORKER / ADMIN

## 已实现的接口

### 工单模块（RepairOrderController）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/orders | 新建工单 |
| PUT | /api/orders | 更新工单 |
| GET | /api/orders/{id} | 查询工单详情 |
| GET | /api/orders/student/{studentId} | 查询学生工单列表 |
| GET | /api/orders/status/{status} | 按状态查询工单 |
| DELETE | /api/orders/{id} | 删除工单 |
