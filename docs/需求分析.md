## 3. 功能需求

### 3.1 智能报修
- [ ] 文字 + 拍照描述故障
- [ ] AI 多模态理解，自动补全楼栋、预约时间、紧急度等字段
- [ ] 生成结构化工单

### 3.2 自助诊断
- [ ] 基于维修知识库的 RAG 问答
- [ ] 能自修就分流，不派单

### 3.3 调度 Agent
- [ ] 按故障类别、位置、师傅排班与时间窗自动派单
- [ ] 冲突检测，支持改约

### 3.4 进度跟踪
- [ ] 状态机全流程通知
- [ ] 支持取消、改约，状态流转幂等可靠

### 3.5 评价与知识沉淀
- [ ] 完成后评分与维修结论
- [ ] 清洗后回流知识库，形成数据闭环

### 3.6 运营看板
- [ ] 维修量、平均响应/完成时长、满意度、高频故障 Top 榜

## 4. 非功能需求

- 诊断准确率：核心指标
- 状态流转幂等可靠
- 响应时间
- 数据安全与隐私
